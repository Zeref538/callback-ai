About callback-ai

A free practice tool for job interviews. You paste a real job post, and an AI interviewer asks you questions about it. When an answer is vague, it asks again.

Say "I improved performance" and the next question is how much, and how you measured it. That follow-up is where real interviews are decided, so it's what this tool practises.

How an interview works

  1. The job post is turned into the handful of skills the role is really hiring for.
  2. Each question goes to whichever skill it knows least about so far.
  3. A vague answer gets a follow-up on the same skill instead of a new topic.
  4. The debrief scores each skill, and every score quotes your own words back to you.

What it runs on

The interviewer is NVIDIA's Nemotron 3 Super model, called from a Python (FastAPI) server on Render. This page is served by Netlify, and optional accounts use Firebase. The code is open on GitHub.
